# Дорожная карта: как сделать валютное приложение с нуля

Памятка для новичка. Идём от простого к сложному. Не перепрыгивай этапы.

## Как вообще устроено приложение

Любое приложение состоит из трёх частей:

1. **Интерфейс** — то, что видит пользователь (поля, кнопки, экраны).
2. **Логика** — что происходит при действиях (нажал кнопку → посчиталось).
3. **Данные** — откуда берётся информация. Для курсов валют это **API** — адрес в интернете, который отдаёт свежие данные.

## Почему начинаем с веб-версии

Веб-страница открывается в браузере и на компьютере, и на телефоне. Не нужны аккаунты разработчика и публикация в магазинах. При этом ты учишь ровно те же технологии, что нужны и для мобильной разработки: **HTML** (структура), **CSS** (вид), **JavaScript** (логика).

## Этапы

### Этап 1. Интерфейс и логика без интернета
Сделать поле ввода, выбор валют, кнопку, вывод результата. Курс пока задан вручную в коде.
Навык: как устроена страница, как кнопка запускает действие, как считать и показывать результат.

### Этап 2. Реальные курсы через API
Заменить ручной курс на живые данные из интернета через `fetch`.
Навык: запрос к API, разбор ответа (JSON), подстановка данных.
Готовые бесплатные API без ключа: `open.er-api.com` (есть сум UZS), `frankfurter.dev` (основные валюты). У Центробанка Узбекистана — `cbu.uz`.

### Этап 3. Довести до ума
Обработка ошибок (нет интернета → показать сообщение и запасные курсы), запоминание выбора, аккуратный дизайн под телефон.

### Этап 4 (позже). Превратить в мобильное приложение
Когда веб-версия работает — два пути:
- **Обернуть в оболочку** (быстро): Capacitor / PWA.
- **Переписать на фреймворк** (правильнее): **React Native** или **Flutter** — один код на iPhone и Android. React Native логично продолжает JavaScript, который ты уже знаешь.

## Что учить и в каком порядке

1. Основы **HTML** и **CSS** — пара дней на азы.
2. **JavaScript** — переменные, функции, работа с элементами страницы.
3. **fetch** — получение данных из API.

Это ~80% пути. Мобильные фреймворки — уже после.

## Твой прототип

Файл `converter.html` — рабочий пример с этапами 1–3 сразу. Открой его в браузере, потыкай, а потом меняй код и смотри, что изменится. Это лучший способ учиться. Внутри — подробные комментарии на русском к каждой части.

**Первые эксперименты для тренировки:**
- Добавь новую валюту в список `CURRENCIES` и в запасные `rates`.
- Поменяй цвета в разделе CSS (например, `#2563eb` на другой).
- Поменяй заголовок и текст под ним.
